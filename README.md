# RongMC 过场歌词

简体中文 · [English](./README.en.md)


为 Ji AFK Cinematic 的电影遮幅增加当前歌曲字幕。MuoniumPlayer 提供歌词和译文时，两种文字会随播放进度出现在画面底部。

## 使用

在 MuoniumPlayer 中播放歌曲后进入 Cinematic 模式。没有歌词的曲目不会显示字幕。此版本面向 Ji AFK Cinematic 2.4.0，并包含一个 SDL 按键状态适配。

## 安装

在 [GitHub Releases](https://github.com/OpenRongMC/RongMC-Cinematic-Lyrics/releases/tag/v0.1.1%2B26.3) 下载 **v0.1.1+26.3**。使用 Minecraft Java **26.3**、**Fabric** 和 **Java 25**。 将发行 JAR 放进实例的 `mods/` 目录。 客户端使用，准备发行版要求的 Ji AFK Cinematic 和兼容的 MuoniumPlayer。对宿主模组升级时同时测试歌词界面。
